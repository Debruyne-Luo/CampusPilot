# 本轮独立审查口径

审查者为执行此次实施的 Codex，依据保存的官方原文及目录字段逐题核对；没有另设独立人员，
不使用任务执行模型或优化器的自评分。以下口径在保留集执行前确定。

- 任务通过：回答覆盖所问的已知事实，未知部分明确，关键事实无错误；需要地点或教师卡时实际返回。
  `result_status=success` 本身不算通过证据。
- 工具选择：办事与政策题须取得相关官方知识；教师题须查询教师目录；地点题须查询地点。
  允许有依据的不同工具组合，多余调用另计数量，不自动判错。
- 事实与引用：检查答复中的办理渠道、资格、期限、保证、办公室及来源是否得到原文/目录支持。
  引用合法与引用支持陈述分别核对。目录题只证明目录契约，不能当成原网页重新审核或现场导航验收。
- 部分回答：有可确认内容时保留它，并说明实时状态、时限等缺口；不能把整个问题一概拒答。
  仅询问未知保证的题目，说明未知及核实方向可以通过。
- 错误拒答：原文/目录已有所需信息，却只称无依据、不查询或不返回可确认部分。
- 关键错误：捏造办理要求、缴费动作、时间承诺、个人办公室/接待时间，或把历史/地图线索当现行政策。
  其他遗漏、冗余和表达缺陷另行说明。
- 耗时从 `AgentRunner.run` 到后台判断结束计算，不包括启动 Python 进程；每次只测一遍，
  报告中位数/观测值，不宣称统计显著。费用按本轮新预留请求结算或保留上界，不包括编辑者成本；
  整个活动的总额另报，包含失败、诊断与未知用量。

开发集用于挑选一个实验候选，冻结后才查看保留集结果。保留集六组不用于再次改写策略。
采用要求是关键错误不增加、通过数不下降，并有明确质量或效率收益；没有明确收益时仍用基线。
这 24 题不替代知识包的原有 60 题发布门槛。

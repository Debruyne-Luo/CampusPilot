# 固定题与独立验收

120 个公开校园测试题，80 development、40 holdout。cases.jsonl 的 SHA-256 在 manifest.json
锁定；不重新生成来适配模型输出。原能力和新审核包按分层分配覆盖地点、教师、4 类
事务、通知、新知识、12 个办公室摘要、历史/废弃/索引/限制和澄清边界。
脚本的 split=development 是默认开发范围，保留集留给规则冻结后的独立验收。

每题锁定问题/前序消息、预期事实、必要前提、引用来源、候选片段、卡片 ID、合理策略
及追加检索标签。正文审批不自动证明题目标注独立核验；标签审核仍为 PENDING。
独立审核人应核查包括人群、学年、金额条件、时效与历史使用限制。
Jev 不得为自己的建议评分并据此通过门槛。

开发者报告只给检索和适配器诊断。任务 PASS 须独立检查：

1. 关键事实正确，前提不漏，不把片段排序分数当可信度。
2. 来源可回溯至当前片段，引用与断言一致；无依据内容为零。
3. 同名、对象/学年不足时澄清；索引/历史/限制片段不变成现行规则。
4. 保持授权目录/卡片与地图行为；模型不能产生新的目录/坐标或扩大权限。

independent-qa.template.json 只提供字段，复制到仓库外填写。必须绑定原基线、
完整 API 答复、性能与 Jev 报告的 SHA，以及全部运行文件字节和固定题 SHA。
需要总体和保留集均 ≥95%，原能力不退步，关键事实/前提/无依据断言零违规。
模板、离线通过测试和自行填写 PASS 都不是独立 QA。
维护步骤及剩余阻断项见 [迁移交付](../../docs/RUNTIME_MIGRATION.zh-CN.md)。

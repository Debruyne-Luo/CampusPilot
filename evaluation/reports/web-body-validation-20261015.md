# 2026-10-15 官方正文获取验证

**CONFIRMED：本轮瓶颈是官方 HTML 的访问防护，搜索返回成功不等于取得可用正文。**
10 条预先固定的新问题只验证正文可得性，没有生成最终答复或运行 Jev 质量比较，不能据此宣布
Jev 有效、无效，或用户问题已正确回答。基线提交为 `43633f87a83bcca18d83a6c20e7c2219eaf74aaa`，
包含当前未提交改动；知识快照为 `kb-229ee34eba99ef34`。当次脚本、读取器的 SHA-256 和题目
固定在 [运行身份](../web-body-20261015/identity.json)，题目见
[固定题集](../web-body-20261015/cases.json)。读取器在运行前后的指纹一致。

## 方法与范围

沿用现有 DeepSeek 原生联网搜索（`deepseek-flash`、Anthropic 兼容接口），取得候选 URL 后，
由应用的 `SafePageReader` 校验公网地址、固定连接地址、保留 Host/TLS SNI 并读取正文。
搜索片段、供应商生成内容和 `encrypted_content` 均未作为已取得的原文。
Tavily 备用提供方未配置，本次没有验证它已接通，也没有调用它。

本机系统 DNS 把学校域名解析到非公网的 `198.18.0.x`，读取器正确拒绝这些地址。
实验使用公开 DoH 隔离本机 fake-DNS 环境，仍通过公网校验及固定地址连接；
这是本地诊断注入，不是生产 DNS 设置。没有访问私网地址、关闭 TLS 校验、执行挑战脚本、
处理验证码或重放 Cookie，也没有修改线上配置。

## 实际结果

- W01–W07 中除 W05 外的 6 个问题获得 HTTP 200 的结构化原生搜索响应；随后共尝试读取
  18 个候选页面，全部因 HTTP 412 防护而失败，应用返回 `limited/page_protection_required`。
- W05、W08 的原生搜索 API 返回 HTTP 503，没有可核算的 usage，未执行正文读取。
- W09、W10 被现有共享预算提前拒绝，没有向供应商发送新的搜索请求。
- 本轮 10 题取得的可用官方正文为 **0 份**。没有把失败搜索或空结果算成成功补证。

6 个成功 API 响应的 `usage.server_tool_use.web_search_requests` 原始计数合计为 **12**，其中一次为 3。
逐块检查实际返回：**6 个正常搜索结果块、6 个 `max_uses_exceeded` 错误块**；额外尝试被供应商拒绝。
不能把 usage counter 解读为 12 次成功底层搜索、突破 `max_uses` 或已产生相应收费。
本次仍保留应用的期限、候选页读取及预算边界，不以搜索结果标题证明正文事实。

另做独立公开 HTTP 对照：四个最初失败的 HTML URL，以及三个新增图书馆 HTML URL，
在固定公网地址的 httpx 和 hostname URL 加 `curl --resolve` 两种客户端下均返回 412。
响应为约 2.5KB 的 UTF-8 HTML，含 `$_ts.nsd`、`$_ts.cd` 等混淆脚本；排除脚本后没有有效正文。
两个客户端结果一致，支持站点 JS 防护这一解释，不能归因为 Host/SNI、PDF 或字符编码错误。

附件是不同情况：[邮箱使用手册 PDF](https://wxc.cdut.edu.cn/jiaoshiyx.pdf)可直接公开读取，
两种客户端均为 HTTP 200 / `application/pdf`，1,518,002 字节，SHA-256 为
`36a862cc391fab815e0d849a8b310b8c245ebeb4018fdb7f3ff03639cd759fd7`。
现有维护工具 `official_knowledge.parse_attachment` 能解析其 50 页、32,126 字文本；
在线读取器不支持 PDF，且该文件超过现行 500KB 页面上限，仍按契约拒绝。
文档元数据创建及修改时间为 2014-12-04，只说明附件的历史属性，不能证明当前端口、容量或政策仍有效。
这份单独探测的附件没有计入上述 10 题补证成功数。

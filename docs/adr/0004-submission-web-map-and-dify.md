# ADR 0004: 10 月 15 日提交版

- Status: **CONFIRMED**
- Date: 2026-10-07
- Approving authority: human Product Owner / Tech Lead
- Approval evidence: 用户明确要求实施“CampusPilot：10 月 15 日提交版开发计划”，优先计算机与网络安全学院。

## Decision

主线为办事或找人 → 查询可信资料 → 定位地点 → 打开高德第三方导航。
保留原三项事务与 RAG，增加独立校园卡补办、地点目录、教师查询和结构化卡片。
采用现有 Python 3.14 / FastAPI / 原生网页实现；Dify Cloud 负责意图提取与组织回答。
业务数据与权限由 Python 管理，Dify Code 节点从真实 HTTP 结果取得 ID；前端不解析模型坐标。
高德提供底图和导航。校园规则来源与坐标来源分别记录；未知位置不补造。

复用 Ubuntu 24、1 核、1 GB、10 GB VPS，单进程、独立虚拟环境、systemd、HTTPS 反向代理。
访客口令与工具凭据分离；聊天限流与工具回调分离。保持内存会话，重启丢失历史。
不新增学校登录、课表、代办动作、数据库或自建校内路径算法。新增费用上限 300 元。

2026-10-07 追加 **CONFIRMED**：用户明确接受域名/HTTPS 新增费用 0 元的方案，
采用 `campuspilot.38-244-61-184.sslip.io` 与免费公开证书，复用现有 VPS。
不购买阿里云域名。地址解析、证书、Dify 回调与国内访问分别验收；免费第三方 DNS
不构成可用性保证。主机地址变化时需同步更换入口、高德限制和 Dify 工具地址。

2026-10-07 追加 **CONFIRMED**：用户明确接受将模型服务商密钥保存到 Dify，
并通过 Token 算力服务平台的 `http://sagalcc.cn:3002/v1` 发送模型请求。
此授权涉及模型平台的 HTTP 明文传输，不改变网页与工具入口的 HTTPS 要求。
模型密钥、Dify 应用密钥与工具 token 分离；原 RAG 应用保留。

2026-10-07 追加 **CONFIRMED**：用户要求以地图为主界面，参考所提供的 Codex 地图截图。
采用大幅地图、顶部统一搜索、分类筛选、底部横向地点卡片与浮动详情；
办事对话、教师查询和事务指南通过可关闭面板打开。支持展开地图及手机布局，
仍使用已有高德底图和同一份业务目录，不引入评分、照片或未经确认的校园点位。

## Consequences

2026-10-08 追加 **CONFIRMED**：用户要求继续完善手机体验，改为“校园地图 / 事务助手”，
扩展原地图地点的可用性，并处理路线规划到导航的差距。当前网页增量保持单体与高德，
接入热点/周边地点与地图选目的地；显式开始前台步行引导才进行持续定位，离开前台或
切到助手时暂停，退出/换目标时清除个人定位。后台、室内和原生导航能力未在本轮交付。
新增地点是高德临时目的地，不自动建立办公室/设备的官方业务关联；详见
[网页引导边界](../WEB_GUIDANCE.zh-CN.md)。下方一次性路线段落保留为前次交付范围。

2026-10-08 追加 **CONFIRMED**：用户明确要求实施“CampusPilot：站内步行路线与查询联动”。
新增页面内一次性步行参考路线，使用现有高德 JS SDK 的 Walking 服务；不自建校内寻路。
现有14个高德建筑候选可作为参考路线目标，不提升资料核验状态；外部导航确认条件独立保留。
只有点击“我的位置”才取得一次浏览器定位，运行时转 GCJ02，仅用于高德算路，不进入 Dify、
持久化或普通日志。支持目录/地图选择起点、失败重试与退出；不包含连续跟随、语音或偏航导航。
唯一业务结果和唯一地点自动聚焦，多候选先选择；手机、桌面同等验收。
本轮允许先交付可用联动，网安楼及当前补卡设备位置是后续数据增量，不阻塞本轮交付。
用户同时授权沿用已有 SSH、备份、验证及失败回滚流程同步发布后端与静态文件。

2026-10-08 追加 **CONFIRMED**：用户明确要求以比赛演示的使用体验为先，减少解释性文字。
答案先给结论与下一步，默认 40–80 汉字，详细说明按需展开；老师房号直接突出显示。
来源、年代和核对备注收进详情，取消重复提醒；地图正常显示时不覆盖说明面板。
使用已找到的公开资料继续开发；无法确定的具体字段简短表达，不自动改写事实批准状态。
已收录高德 POI 可直接打开对应高德详情页；不以此冒充学校业务点或人工确认的导航目标。

2026-10-08 追加 **CONFIRMED**：用户选择在本机保存专用 SSH 私钥，供 Codex 后续直接
部署；无需保存 VPS 密码。现有 root 账户、主机指纹校验和已有登录保持，公钥安装不
改变其他服务；私钥保存在仓库外受限目录，源码包与日志不包含私钥。

本决定接续 ADR 0003，不改变合成演示的隔离与人工事实核验要求。

公网部署及学校事实验证不能从代码测试推定完成。
高德个人认证和 JS API Key 已准备；免费入口已部署，公网证书及健康/未授权检查通过。
SSH 使用 root 与密码，密码保留用户本机。
上线前先只读检查 VPS，保留已有服务。到期日 2026-11-04，需要覆盖之后评审时再续期。

# ADR 0005 — 后端问答与显式知识发布

日期：2026-10-10。状态：**CONFIRMED**。
批准方：人类 Product Owner / Tech Lead。
批准证据：本会话用户明确要求实施 CampusPilot 两阶段迁移计划，并进一步指定 Jev
通过 OpenRouter 接入、当前先完成代码与离线验证。尚无 GitHub 批准链接。

用户问答的多段 Dify 编排和后端回调增加时延，也使运行依赖 Dify Cloud。
用户批准先迁移路由和生成，再迁移知识问答；当前生产版本必须按实际发布字节留档。

第一阶段由 Python 统一权限、校园目录、教师、事务及通知路由，直接调用业务函数和
可替换的 HTTPS 生成模型。保留已有确定性路径；新增直接回答规则只有在固定题评测、
真实 Jev 影子建议和独立 QA 达标后才进入生产。其他知识问答暂留冻结 Dify 路径。

第二阶段使用不可变知识快照和轻量中文词法检索。Dify 负责正文维护，通过显式维护命令
读取、校验、预览、生成候选包、发布或回滚。片段稳定 ID、正文哈希、审批与适用元数据
共同决定是否可发布。正文变化使旧审批失效。每次请求使用同一知识版本；Dify 故障不会
阻止后端使用最近成功版本，模型故障则保留本地受限结果。

保留单主 Agent、Python 模块化单体、内存会话、JSON 资料和现有高德功能。
生成模型的具体服务商/模型仍为 **OPEN**，生产适配器与合成演示接口分离。
向量检索、Skill 选择、工具决策仅定义接口，实际技术选型和部署为 **DEFERRED**。
不新增数据库、向量服务或运行时 Agent。

Jev 使用 OpenRouter 的 typed decisions 接口，只发送固定脱敏题和公开校园摘要。
它只能选择提供的候选项；报告策略建议、追加检索、充分性和重排，不能改变线上路由、
证据、权限或工具执行。超时、错误、低置信度保留原候选。收益由独立标签判定。
每阶段外部推理最多 5 美元、默认最多 1,000 次；未知价格不启动批跑。

验收要求沿用用户计划：固定 120 题（80 开发、40 保留）；总体和保留集通过率均
≥95%，原能力不退步，关键事实、必要前提与无依据断言零违规；同环境并发 2、
每路径/温度至少 100 个有效完整 API 测量；简单路径 P95≤2 秒且较 Dify 快至少 50%，
RAG P95≤15 秒。独立 QA 验证故障、权限、地图/移动端，并在第二阶段阻断 Dify 网络。
没有当前发布基线或门槛未通过时，不能宣称迁移完成。

本 ADR 仅替代 ADR 0004 中 Dify 承担在线编排/RAG 的部分，保留其网页、地图、目录、
部署和只读权限边界。配置与交付状态由 [迁移文档](../RUNTIME_MIGRATION.zh-CN.md) 维护。

# ADR 0006 — 在线补证、临时地图地点与用户图片

日期：2026-10-14。状态：**CONFIRMED**。
批准证据：用户在本会话明确要求实施《理小龙后端完善方案：统一地点查询、联网补证与图片理解》。

保留一个 Python 主 Agent。现有文本问答接口与办理清单兼容；发布、合并与真实校园路线验收独立进行。

- 地点查询先查目录精确名称、别名和教室编号，再通过高德 Web 服务补查。临时候选采用
  `amap:poi:`，保持 `location_only` 来源，不建立办公室、教师或办事窗口关联。
  唯一明确匹配直接展示地点卡；模糊或多候选必须由用户选择。点击“带我去”才进入现有引导流程。
- Jev 从影子评估扩展为在线证据判断：搜索前判断是否补证，搜索后判断能否作答，每轮至多两次。
  此授权仅覆盖公开资料、受限只读检索；Jev 和模型均不能改变权限或来源权威性。
- 联网优先 DeepSeek 原生搜索，Tavily 免费账户作为备选。每轮共用十秒截止时间、最多两次搜索、
  三份网页正文。原生结构化来源、直接正文和供应商提取原始正文保留不同出处；模型概述不是证据。
  学校事实优先官方材料，第三方作为标明来源的线索；缺证据明确返回未解决项。
- 搜索和在线 Jev 共用每天一美元预算，最多一百次联网流程；价格未知不调用，Tavily 不自动付费。
- 用户图片每条至多三张、原文件每张十 MiB；JPEG、PNG、WebP 经校验和去元数据后临时保存。
  有效期沿用当前匿名会话固定一小时；新对话清理，重启失效，不进入知识包或办理清单。
  清晰可读文字可辅助查地点，外观猜测不能建立导航目标。阅读原文明确归属用户图片，不能升级为现行校规。
- 生成故障不触发“知识不足”的推断，不展示无关检索全文。金额、楼层、入口和用户教室号分别校验来源。

本 ADR 替代 ADR 0005 中 Jev 仅有影子职责的限制，以及旧地图发现仅限浏览器的限制。
来源政策、个人实时位置留在浏览器、室内路线延期和人类最终发布权限继续适用。

实现、配置和当前验收结果见 [交接记录](../EVIDENCE_MEDIA.zh-CN.md)。批准方案不等于上线或质量门槛已通过。

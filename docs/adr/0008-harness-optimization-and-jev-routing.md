# ADR 0008 — 比赛版 Harness² 优化与 Jev 路由

日期：2026-10-20（America/Los_Angeles）。状态：**CONFIRMED**。
批准证据：用户明确要求实施《CampusPilot 比赛提交方案：校园交互、Harness² 优化与 Jev 决策》，
并批准首轮所有实验共计 20 美元硬上限。本轮不包含 Git 推送、合并或生产发布授权。

保留单主 Agent 和桌面优先的现有网页。图片理解不扩展。Search／Fetch 由用户安排的独立工作负责。

- Harness² 固定提交 `1cfe254e8d25b15f37048c3730134686abe60335`，原优化算法保持原样。
  新增 CampusPilot 适配器、两份纯文本策略配置，以及可编辑配置描述的注册补丁。
- Python 3.12 优化器通过 JSON 子进程调用 Python 3.14.7 的真实 AgentRunner。
  原 OpenCode 改进者的每次模型请求必须经过统一计费网关；原始密钥不进入其工作目录。
- 正常问答加载经审查的不可变策略；独立实验室显示真实配置变化、执行对照、来源身份和成本。
  公开接口只读，实验由本机命令启动，失败和无提升结果如实保留。
- Jev 从既定工具组合中选择路由，程序构建参数并执行权限、依赖和引用校验。
  每轮路由至多一次、证据判断至多两次，总计至多三次；单次最多两秒。
  不确定、故障和耗尽时使用现有规划与证据，不允许新增材料绕过核验。
- 优化器不能修改事实、权限、工具 schema、引用和适用性要求、评测标签或 Jev 阈值。
  开发与保留任务按来源/事项分组，参考答案不提供给执行者和改进者。
- 代码接入、实验完成、质量提升与知识发布分别验收。候选须经独立留出比较后才能采用；
  无明确收益保留基线，不把运行框架本身等同效果提升。

本 ADR 扩展 ADR 0006 的 Jev 职责与调用预算，不改变 ADR 0007 的知识发布门槛。
设计、操作和实际验证记录见 [比赛设计文档](../SUBMISSION_DESIGN.zh-CN.md)。

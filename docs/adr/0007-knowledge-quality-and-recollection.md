# ADR 0007 — 知识重采、适用性治理与分层验收

日期：2026-10-17（Asia/Shanghai）。状态：**CONFIRMED**。

批准方：人类 Product Owner / Tech Lead。批准证据：本会话用户明确要求实施
“CampusPilot 知识库优化、资料重采与质量验收计划”；尚无 GitHub 批准链接。

## 背景

扩大资料数量不能自动修复适用性、解析或回答错误。现有混合检索、不可变知识快照与回滚
继续使用；通过已有 official_knowledge 管线扩展采集、原文修订与证据校验。

## 决定

- 本轮覆盖成都校区及全校通用公开资料，面向在校本科生和研究生，包含办事政策、部门、
  公开联系方式、教师与地点。历史资料归档追溯，不新增在线历史查询或定时更新。
- 扩展 v2 知识契约，原 v1 字节、版本与哈希保持可读。适用校区、人群、学年、有效期、
  条件及例外均有原文依据；未知值不推断。直接检索与 Agent 使用同一适用性规则。
- 保存文档及修订身份，按条款稳定 ID 更新；失败保留最近成功内容，缺失和较新时间戳
  不自动证明政策废止。已确认失效或替代内容不用于默认现行问答。
- 标题、条款、表头、脚注和父章节可追溯；上下文扩展有数量及字符预算，遵守来源、
  修订和适用范围。引用绑定实际保留的证据。
- 服务区分 directory、guide、procedure。目录和指南可无步骤；完整流程需要逐步来源
  支持。旧数据缺字段时不自动升级，已保存浏览器清单及进度保持可读。
- Firecrawl 为可替换采集适配器，抓取结果先进入候选。仅用现有免费额度，不充值、升级
  或自动加购；小试预留额度上限 150 credits。网页、附件、图片与 OCR 分别验收。
- 新增 120 个场景（60 开发、60 保留、六类各 20），按来源/事项分组隔离。金标绑定原文
  事实与版本，未标注不等于拒答；检索重合不等于答案和引用正确。独立核对后才认证金标。
- 发布审查要求 60 个保留场景至少 54 个通过、关键事实零违规、原能力不退步，并完成相关
  回归。缺原文、缺真实答题或未审查时保持未验收；不能以检索分数代替。
- 结构化目录与 RAG 候选共同校验和打包；涉及两者的候选不得单独切换知识指针。

## 后果与边界

无需新增向量服务、GraphRAG、运行时 Agent 或替换嵌入/重排模型。采集效果与架构实现
分别报告；候选构建不代表全量完整、发布达标或线上已更新。合并和上线切换另行执行。

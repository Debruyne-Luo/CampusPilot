## Windows 解压兼容修复

首版外层 ZIP 含最长 271 字符的归档路径，Windows 压缩文件夹引擎无法列出内容；Python CRC 与解压通过不能覆盖这一兼容问题。使用相同 Windows 引擎已复现旧包失败、短路径对照成功。

本版外层仅保留短路径，将原知识发布原封不动封装在 `data/knowledge.zip`。首次自检或启动会校验并还原全部 259 个原文件，含指针、发布清单及其绑定文件；所有原文内容、知识版本和前端资源身份不变。新增资源包校验、还原、已有文件损坏及路径越界检查，并用 Windows 压缩文件夹引擎实际解压后逐文件核对哈希。

复验还捕获扩展路径中的 `?` 被 SQLite 当成 URI 查询分隔符，导致混合检索索引降级。给索引预检及加载入口统一转义文件路径，并以相同真实索引回归验证。此修改只处理文件路径，不调整问答、检索排序、提示词或知识事实，固定 60 题未重复付费运行。

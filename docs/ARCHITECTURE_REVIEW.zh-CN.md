## 已实现的行为

- `observability` 使用独立 `campuspilot.operations` logger，经既有 stderr/journal 出口写 JSON 元数据。
  记录服务器 request_id、知识版本、允许/拒绝、错误码、拒答/降级决策、取消和耗时。
  字段和值均受白名单限制；不记录原始问题、答复、工具参数、图片观察、URL、位置或异常消息。
  同步线程和延迟 shadow 任务继承本轮上下文；日志 I/O 故障显式失败。
- 每轮在工作线程获取一次快照，之后检索、追加检索和 Jev 共用该对象；相同目录的 Store 别名同时固定。
  空快照也固定，作用域退出后恢复原有加载、校验与回退。Jev 对含正文哈希的行拒绝正文不匹配的候选；
  旧的缺哈希行保持兼容。新轮继续检测 raw、snapshot、索引损坏。
- `ExecutionBoundary` 复用现有只读权限策略，要求应用声明能力风险和 allowed_tools；注册本身不授予权限。
  工具、Jev、联网搜索和 Agent 的 embedding 预取均经过该入口。`public_read` 表示不写校园业务数据，
  不表示没有联网、费用或配额副作用；供应商开关、输入约束、限流和预算仍在原适配器内。
- `Evidence` 与 `ResponseBuilder` 从 executor 拆出；各阶段共用一轮 Jev 缓存和两次判断上限。
  检索内过滤、生成前判断、搜索前/后来源准入各自保留。shadow 不等待判断，故障保留原流程。
- 已有目录或办理证据时，联网前澄清不再隐藏整个可用答复；提示词要求回答已证实部分并明确未知。
  未注册、非法或权限被拒绝的模型工具调用返回本次错误，不能误用上一次工具结果。
- GitHub Actions 使用锁文件安装依赖，运行 Ruff、mypy、pytest 和既有 Node 契约测试。
  Python 检查分别运行，某项失败不会隐藏其他检查结果；没有删除测试、降低断言或新增跳过。

```powershell

$env:PYTHONUTF8='1'
$env:PYTHONDONTWRITEBYTECODE='1'
$env:PYTEST_DISABLE_PLUGIN_AUTOLOAD='1'
uv run --offline --frozen --all-extras ruff check --no-cache
uv run --offline --frozen --all-extras mypy --no-incremental
```

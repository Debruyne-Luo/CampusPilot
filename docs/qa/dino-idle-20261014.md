# 无有效定位时恐龙引导消失：本地修复

## 根因与修正

`map-frame.js` 的位置平滑只保存经纬度。等待有效 GPS 的下一帧仍从此对象读取朝向，得到 `undefined`，随后产生 `NaN` 并传入模型及地图镜头。正式网站的桌面复现实际报出 `Invalid Object: Pixel(NaN, NaN)`；同一场景在浏览器中保留朝向后恐龙恢复显示。

本次把无 GPS、非演示分支的目标改为 `{...s.shown, bearing: s.bearing}`，沿用最后有效朝向。没有改变定位申请、路线计算、GPS 分支或演示模式。

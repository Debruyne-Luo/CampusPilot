# 双模式地图与前台步行引导

2026-10-08 用户反馈：手机页面容易误缩放、地图只有20条目录、路线规划缺少导航。
本轮沿用原生网页/FastAPI/高德与既有备份发布流程；不新增框架或校园路网。

## 使用与能力边界

- 校园地图与事务助手是两种空间；手机底部切换，桌面顶部切换。对话/资料/教师/事务
  在助手空间查看；查询目标可切回地图。保留历史与滚动位置，切换不重发聊天。
- 页面使用 `touch-action: manipulation`，手机输入/选择字体至少16px，触控按钮加大；
  地图自己的平移/双指缩放保留，浏览器辅助缩放仍可用，不全局关闭用户缩放能力。
- 20条目录仍是业务关联数据；高德热点显式开启，可点击获取地点详情。目录没有命中
  时搜索成都校区中心2公里周边，单次最多10条；已有结果可“搜索更多高德地点”。
  这是校园及周边搜索范围，不是学校精确围栏，也不保证高德完整收录每个房间/设备。
- “地图选目的地”允许选任意位置后由高德算实际道路；点选位置不生成建筑/业务事实。
  高德新增POI只用于临时目的地，不把学院地址推断成老师办公室或补卡设备。
- 路线就绪后可“开始步行引导”：用户主动允许持续GPS；WGS84经高德转换为GCJ02，
  显示当前位置、下一步及剩余距离/时间。拖动地图停止自动跟随，可手动恢复跟随。
  偏离参考路线时提供从当前位置重新规划；地图失败保留目标与分步文字。
- 底图加载失败可单独“重新加载地图”，不刷新整页、不丢失对话；旧iframe的就绪/结果
  消息通过地图代号过滤。引导时下一步和剩余距离优先显示，个人定位保持在卡片上方。
- 切到事务助手、页面离开前台或锁屏时暂停；继续需要点击。退出/换目标/更换起点
  停止跟踪，清除个人定位。前台网页不承诺后台/锁屏持续导航或室内到房门的定位。
  高德外部入口及原有导航确认规则独立保留。没有生成直线替代道路。

## 定位判断

转换最多每6秒一次；旧于15秒的GPS不采用，精度差于60米不更新进度。
沿高德几何做局部路段匹配，抑制突然跳点；偏离阈值取35米与1.5倍定位误差的较大值，
持续至少6秒才提示重新规划。到达须精度不差于25米、进入终点20米范围、进度至少85%，
并获得相隔至少6秒的两次有效定位。阈值是工程初值，校园真机步行后再调整。
到达仅表示目的地附近，不等于校园事务办理完成。

## 依据与后续

地图热点及手机默认值见[高德 JS API2参考](https://a.amap.com/jsapi/static/doc/index.html)，
地点搜索见[官方插件教程](https://lbs.amap.com/api/javascript-api-v2/guide/services/autocomplete)，
路径仍复用[官方 Walking 方式](https://lbs.amap.com/demo/javascript-api-v2/example/walking-route/walk-custom)。
浏览器持续定位须HTTPS及显式授权，见[MDN watchPosition](https://developer.mozilla.org/en-US/docs/Web/API/Geolocation/watchPosition)。

真实热点/搜索与算路可在浏览器验证；移动视口和合成GPS只验证布局/状态，不代表手机真机
步行、iOS Safari、校园网或建筑入口已验收。长期若需要锁屏语音、稳定偏航重算，评估原生
导航SDK/平台小程序；当前比赛演示先展示网页中可实测的任务到行动流程。

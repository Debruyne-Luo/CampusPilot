## 可操作预览

Chrome 独立窗口标题：`新版恐龙与引导修复 · 本地预览（未发布）`。已准备珙桐餐厅 → 东区图书馆的真实步行路线，点击「开始路线演示」即可。

地址虽然是线上域名，但只有这个隔离浏览器把页面与 `/assets/` 替换成本地 8875 服务；问答 API、高德底图和路线仍用真实服务。普通浏览器打开同一网址看到的是已部署版本。这不是一次发布。本轮没有提交问答或保存生产对话，测试只使用公开校内地点和真实地图路线。

复现预览：先按项目方式启动本地服务于 8875，再用 `playwright-cli -s=guide-preview open about:blank --config tests/preview-window.config.json --headed`，执行 `tests/browser_rounded_preview.js`。必须在仓库根目录运行。`viewport:null` 让页面跟随窗口，固定截图尺寸只在 QA 会话设置。

## 修复与取舍

1. 引导结束同步清理帧循环与模型，并恢复路线按钮，避免只清空引导卡后无法再次开始。
2. 用零时长的新高德镜头操作终止未完成的引导入场 tween，避免退出后旧动画再次把地图拉成倾斜视角。普通地点选择与两栏动画未改。
3. 模型异步加载有代次校验；结束后返回的旧模型立即释放，不重新占用地图。
4. 桌面只允许手选起点及路线演示，不申请 GPS 或方向传感器；持续显示「不代表你的实时位置」。窄屏保留原定位入口。
5. 演示进度原位更新文本，保持按钮 DOM，避免进度刷新发生在按下与抬起之间而吞掉点击。
6. 动画控制暂停／继续／结束；「退出路线」同时清除路线。「结束演示」保留路线供重新演示。
7. 饱和青蓝机身、象牙白胸腹、方形学士帽和粗金色帽穗沿用用户高清雕塑图参考；四足与尾巴服务地图背面观看，不用首页大图挤占阅读空间。
8. 脊背大斑点与胸腹均为贴合表面的凸起几何（非贴图），并保留完整地图下载与渲染预算；牺牲地图尺寸无法辨认的细节以降低下载和渲染负担。
9. 图标直接使用用户提供的透明 PNG；统一页头、favicon、touch icon、manifest、二维兼容模式。

## 实施边界

- 桌面样式在 `min-width:1280px` 生效；现有窄屏与手机布局保留。
- 保留 `campuspilot:handling:v1` 数据格式与原 store；不改后端、模型、检索或学校资料。
- 地图继续使用真实 `/map-view` 和现有地图协议，不把设计示意地图转为业务数据。
- 品牌 PNG 用于页头 / 首页；原导航恐龙模型不变。
- 设置仅提供已在本轮实现的本浏览器阅读字号与减少动效；不提供账户、同步、模型配置等虚构功能。
- 未提供服务端取消接口，不显示「停止生成」；连接中断保留未完成文本并允许重新提问。
- 引用展示现有 API 的标题、发布者、日期、适用范围与链接，不编造逐句支持映射或页码。

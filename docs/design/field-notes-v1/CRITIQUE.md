## 每屏复核依据

| 页面 | 视觉依据与取舍 |

## 客观核对

- 16 个最终 SVG 均有明确 width / height / viewBox。
- 16 张最终浏览器 JPEG 均核对为请求的 1440×900 或 1280×900。
- 使用浏览器文本边界检测：最终无画板外文字；同屏文字矩形无大于 3px 的双轴交叠。
- 检测不替代视觉判断；第一轮路线遮挡即由截图发现，单纯文字越界检测无法发现它。
- 文字对比：主字/纸白 11.42:1；次字/纸白 5.11:1；次字/证据底 4.80:1；次字/地图底 4.79:1；朱红/浅赭 5.00:1；白字/绿按钮 7.51:1；水域标签 5.51:1。
- 动态行为、真实地图、无障碍交互和长内容压力测试属于后续应用实现验收，不以本次静态通过代替。

## 2. 为什么选这个方向

| Direction | 布局和视觉重心 | 优点 | 放弃或采用理由 |
| --- | --- | --- | --- |
| 01 对页手簿 | 左侧阅读约 56%，右侧地图约 44%；答案标题与结论先被看见 | 长答案、引用和位置同时可见 | **采用**：兼顾问答、检索、地图三项核心能力，索引能贯穿文字与空间 |
| 02 测绘工作台 | 左地图约 66%，右紧凑对话约 34%；地图优先 | 地点发现、路线探索突出 | 不采用：右侧长政策正文阅读受限，桌面会频繁纵向滚动 |
| 03 办事路线册 | 顶部事项摘要，左步骤约 46%，右地图约 54%；下一步优先 | 连续办事流程明确 | 不采用：纯知识问答容易被迫进入并不适用的任务阶段 |

最终精排采用 **55% / 45%**：1440 下分界为 x=792，1280 下为 x=704。相对方向草案略增地图宽度，让地图搜索框、长地点名及浮层保有空间。

概念来自野外记录、测绘索引和标本标签。纸白只作为平面底色；不加入纸张噪点、卷边、假等高线、罗盘装饰或复古道具。首页主题条目、引用条目与地图标记使用不同形态，避免把所有信息装入一套圆角卡片。

### 5.2 响应规则

- **1280–1399**：55/45 双栏；左页水平内边距 32，保持正文 16；页面标题可两行；引用元信息逐项换行；地图浮层不与右上工具条重叠。
- **1400–1599**：55/45 双栏；左页水平内边距 48；地图始终完整占据右页。
- **1600 及以上**：左阅读页宽度上限 880，正文内容上限 784；新增宽度给地图，不把正文无限拉长。
- **小于 1280**：不在本轮验收范围；不自动切换移动底部抽屉，不冒充已设计移动版。
- 浏览器高度下降时，页头保持，提问框贴工作区底部；左页内容独立滚动，地图尺寸不随回答变长反复重排。
- 长来源名、URL、机构名必须折行，不能挤出右边界。来源外链显示“查看官方原文”，不直接以长 URL 充当操作标签。
- 1280 稿是按上述规则重新排布的独立画板，不是把 1440 截图缩小。其可读性不替代实现后的真实响应式测试。

## 6. 核心页面

### 首页

入口顺序是标题 → 三类事项索引 → 两个具体问题 → 提问框。索引行以横线分组，不做三张同款卡片。右页保持校园总览，搜索始终可达。空首页的可用空间用于提供问题入口，不放装饰性吉祥物大图。

### 问答与证据

用户问题成为条目标题，回答正文直接排版。检索过程完成后折叠为一行，可重新展开。优先级为结论 → 会改变行动的重要条件 → 准备与步骤 → 地点 → 来源。不同任务只呈现适用内容；找老师时显示姓名、机构、办公室及来源，不凭空添加材料清单。

答案中地点用 `01`、`02` 编号，证据用 `[1]`、`[2]`；二者不得复用同一视觉语法。编号在同一条回答中保持稳定，距离排序变化不改写地点身份。新回答进入时更新当前关联集合，历史答案中的编号按所属回答解释。

点击引用，在同一阅读栏展开证据，不盖住地图。展开位置靠近点击锚点，保留原问题与关键结论；03 画板是展开后滚动到证据区的代表视图，不意味着删除准备清单。关闭后回到原阅读位置。

证据须同时表达标题、发布机构、发布/版本日期、适用范围、原文链接和已知限制。“采集于”与“发布于”分开；未知发布时间不拿采集日期冒充。不使用“已核对引用”暗示内容必然现行、业务一定可办。

### 地图 / 路线

地图导航入口切换到地图任务上下文，但保留左侧阅读与提问能力；不把地图切为吞掉对话的全屏。地点搜索区分维护目录与高德 POI，标出来源类别。POI 可用于定位，不自动关联老师办公室、补卡设备或受理窗口。

起点未确定：提供“从地点出发 / 地图点选 / 使用我的位置”；桌面默认鼓励明确选择地点。定位需用户主动触发，拒绝后不阻断手动起点选择。规划成功后展示地图服务真实返回的时间、距离、路线与步骤。路线浮层必须避让起点、终点和主要转折点；04 稿将目的地摘要上移，并移除重复“规划路线”按钮。

本交付地图建筑、道路、水域、路线与“约 8 分钟 / 620 米”均为**明确标注的设计示例**，不得作为校园导航数据使用。地点名称来自现有目录，画板位置不表示真实地理坐标。开发必须换回真实地图与真实路线，不能描摹这份示意图生成业务数据。

### 设置

左页偏好，右页预览；不用空地图占用设置页。设计范围仅包含正文字号、引用默认展开、地点联动与减少动效，偏好保存在当前设备。恢复默认只影响这些偏好，不清空对话或材料勾选。

系统 reduced-motion 为真时始终尊重系统设置；界面显示“系统已开启”，不得用应用开关覆盖。定位权限交给浏览器管理，不提供看似可授权系统权限的虚假开关。本轮设置页全部是新增设计。

## 8. 动效规范

动效只解释“记录进来、出处展开、地点对应、路线确定”。禁止持续扫光、弹簧回弹、无限漂浮、逐字强行打字、装饰性渐变闪烁。网络事件抵达才改变事实状态，动画不延迟可读内容。

缓动命名：E-out = `cubic-bezier(.22,1,.36,1)`；E-read = `cubic-bezier(.2,.8,.2,1)`；E-state = `cubic-bezier(.2,0,0,1)`；E-route = `cubic-bezier(.4,0,.2,1)`。

| 核心交互 / 触发 | 时长 | 缓动 | 变化与目的 |
| --- | --- | --- | --- |
| 顶部问答 / 地图 / 设置切换 | 180ms | E-out | 选中线移动，内容淡入；保持工作台位置感，不滑走整屏 |
| 首页点击主题 | 160ms | E-read | 原区域展开对应问题索引；帮助把主题转成问题 |
| 点击示例问题 | 120ms | E-state | 写入提问框并聚焦，用户可修改后发送；避免误触直接提问 |
| 输入框聚焦 | 120ms | E-state | 边框变绿；不改变几何尺寸 |
| 发送问题 | 180ms | E-out | 新条目向上进入 6px，提问框立即响应；保持问题与回答的连续性 |
| understanding / plan / tool_start 到达 | 160ms | E-state | 对应状态行出现；不创建虚假百分比 |
| tool_end 到达 | 120ms | E-state | 点位与状态文字同步变更；不使用庆祝动效 |
| answer_delta 到达 | 0ms | 无 | 按服务流更新文本，不叠加逐字动画；保留读者选区 |
| final 到达 | 180ms | E-read | 在现有阅读位置归整结构，结束状态栏；不先清空全文再重建闪屏 |
| 自动跟随新内容 | 140ms | E-read | 仅当读者位于底部 80px 内；向上阅读时停止跟随，显示“有新内容”入口 |
| 停止生成 | 0ms 状态切换 | 无 | 立即停止客户端接收并保留部分内容，标记未完成；不假装后台一定停止计费或执行 |
| 清单勾选 / 取消 | 120ms | E-state | 方框实填和计数同步；不划掉仍有用的办理要求 |
| 点击引用编号 | 220ms | E-read | 原栏证据展开，保留锚点；支持核对后返回正文 |
| 收起引用 | 180ms | E-read | 证据区域收起并恢复原阅读锚点，不顶走提问框 |
| 查看官方原文 | 0ms | 无 | 新标签打开原文，保留当前问题上下文 |
| 点击答案地点 | 320ms | E-out | 文字编号立即变朱红，地图平移并高亮同号点；建立两页对应 |
| 点击地图标记 | 180ms | E-read | 同号地点文字高亮、唯一摘要出现；不擅自滚走正在阅读的答案 |
| 地图搜索输入 | 250ms 防抖；120ms 结果出现 | E-state | 结果列表稳定更新；过期请求不覆盖新关键词 |
| 切换地点分类 | 160ms | E-state | 仅更新筛选与相关标记；保留地图中心，避免重新飞入校园 |
| 选择 / 更换起点 | 180ms | E-read | 展开选择区，地图点选提供准星；准星只在点选模式出现 |
| 请求定位 | 0ms 触发权限；160ms 显示结果 | E-state | 明确“正在定位/不可用”；不假定权限已给，不用虚假移动动画 |
| 路线返回成功 | 最多 450ms | E-route | 先显示真实距离与时间，再沿路径描线一次；解释方向，不做无限流光 |
| 路线规划失败 | 120ms | E-state | 显示原因与换起点入口，旧路线标为过期；不把旧线当新结果 |
| 开始引导 | 220ms | E-out | 左栏路线摘要切为引导信息，地图保留终点；真实 GPS 与演示明确区分 |
| 到达 / 结束引导 | 180ms | E-read | 出现“已到达建筑”或“引导已结束”；不宣称业务办理完成 |
| 字号、引用偏好改变 | 0ms 布局；120ms 选中状态 | E-state | 右页即时预览；文本不通过缩放动画模糊变化 |
| 恢复默认偏好 | 160ms | E-state | 偏好与预览同步，显示已恢复；不操作对话和清单 |
| 服务中断 / 无依据 | 120ms | E-state | 状态文本替换，保留问题和已有内容；不震动、不红色全屏 |

减少动效：地图立即定位，路线一次性显示，展开/收起不做位移动画；可以保留不超过 80ms 的颜色变化，也可完全关闭。所有关键状态均能从静态文字判断。

本交付逐项评审了动效与概念的关系；截图不证明动画运行、帧率或真实时序已经验证。上表用于后续实现及验收。

## 9. 状态与失败路径

| 状态 | 设计要求 |
| --- | --- |
| 服务连接中 / 不可用 | 页头真实显示连接状态；发送禁用但保留草稿，地图可用性独立 |
| 流式生成 | 过程与已收到正文并存，允许停止；无新地点结果时保持校园总览 |
| 需要澄清 | 一次询问会改变结果的缺失信息；不显示假完成结论或预先推荐地点 |
| limited / 降级资料摘要 | 明示“资料摘要，未生成完整答案”；不套用成功状态措辞 |
| 没有依据 | 解释检索范围不足，并提供补充事项/身份/标题的途径；不捏造推荐 |
| 连接中断 | 保留已收到片段，醒目标记未完成；重试保留草稿和准备项 |
| 地点无坐标 | 显示“暂无位置”，隐藏导航动作；名称可继续作为问答上下文 |
| POI 搜索无结果 | 保留查询与地图，提供修改关键词，不能渲染空白工作区 |
| 地图加载失败 | 同尺寸保留维护目录列表和重试入口；示意图明确非导航，不允许规划路线 |
| 定位拒绝 | 切换手动起点；不反复请求权限 |
| 路线不可用 | 保留起终点，给出换起点与重试；旧路径显式失效 |
| 连续追问与历史 | 当前问题优先；历史内容仍可滚动查看，新对话不清空全局偏好 |

## 11. 精修取舍与开发验收

1. 保留原有理小龙小尺寸标识，品牌变化主要发生在排版和信息关系，避免本轮扩大为 logo 重做。
2. 宋体只承担标题，让长篇办事答案仍能快速阅读。
3. 55/45 固定双栏维持稳定参照，避免答案一来地图就被挤走。
4. 地图页沿用阅读宽度，保证问答和路线之间切换时输入框位置不跳。
5. 引用在阅读栏展开，用户可以核对来源同时保留地图位置。
6. 路线态把地点摘要放上方并去掉重复按钮，以完整展示起点、终点和路径。
7. 警示朱红加深，优先保证小字可读性而非保留最初色样。
8. 短回答和生成中允许为后续内容保留空间，不填充无关资讯或装饰；首屏仍提供明确状态、后续操作与独立地图。
9. 设置右页用于效果预览，使桌面宽度服务于决策。
10. 地图示意与真实导航明确分开，让后续开发替换数据时保留真实边界。

实现后必须另验：两种宽度与长内容、18px 字号、键盘顺序、读屏状态播报、SSE 中断和停止、真实地图起点选择、旧请求竞态、图层遮挡、系统减少动效、地图供应商标识。不要把本次静态设计通过等同于上述运行验证。

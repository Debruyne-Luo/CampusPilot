证据为 [performance-summary.json](performance-summary.json)、[performance-trace.json](performance-trace.json)。trace 去除 args、网络、截图与响应，只保存允许列表中的时间线事件名、时长和线程信息，可导入 Chromium/Perfetto 查看。p95 为 25ms，因此不能宣称每帧都满足 60fps；本次窗口未见 >33.4ms 间隔，不代表冷启动、弱设备、网络请求或导航模型均达到同样性能。

5. **截图截到 GSAP 中间帧 → 修正**：静态截图等待布局完成；另外用真正录像展示动画，不以 CSS 截图选项假定 GSAP 已结束。

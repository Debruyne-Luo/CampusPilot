# 知识采纳、适用性与修订证据

**CONFIRMED（2026-10-17）：** 用户批准知识库优化与系统复核计划。本实现保留
BM25、BGE-M3、RRF、SQLite 和不可变版本，扩展现有 `official_knowledge.build()`。
本地实现与自动化通过不代表资料已重采完整或真实模型质量验收完成；候选发布与上线另行处理。

## 采纳与失败边界

采集包中的发现记录和抽取候选不取得知识权威。采纳仍要求完整可见正文、准确的文件字符位置、
正文/附件哈希、逐条适用性原文和校验日期。挑战页、截断正文、未核验 OCR、摘要及目录不能作为完整政策。
原始文件和每个修订的采纳标注保存到候选包的 `raw/official/documents/`；重复导入保持幂等。
某文档失败、正文丢失或未再次出现某条款，都保留该文档上次成功资料，不推断废止。

条款 `disposition=retire` 需要同一采集正文中的 `repeal_quote`，并包含明确废止、停止执行、
失效或替代措辞。它保留新原文和历史记录，但停用该稳定条款 ID；普通 `exclude` 仍只是不采纳此次候选，
不能作为删除或废止指令。对整部制度的替代范围必须先核验，不能凭较新发布日期批量停用。

官方公众号与其他官方正文使用一致的 URL 检验入口。Firecrawl 适配包通过既有 `http` 通道导入，
同时提供 `source_capture.provider=firecrawl-v2`；此类原文范围标为
`complete_provider_extracted_document`，不会冒称原始学校 HTTP 响应。
`source_capture` 随修订保留；供应商响应仍需正文校验，成功采集不会自动取得采纳权威。

## 版本化契约

旧 schema v1 的新字段默认值从规范化哈希体排除，旧知识版本及磁盘文件保持不变。
使用新增证据字段的候选自动采用 schema v2；v2 哈希绑定新增字段，不能将 v2 内容伪装为 v1。
向量索引仍绑定具体知识版本与片段文本哈希，必须由发布流程生成或校验匹配索引。

v2 条款新增字段：

- `document_id`、`revision_id`：稳定文档与这次原文/标注修订；后者绑定采集包标注及所有文件哈希。
- `campuses`：明确校区；`unknown` 保持未知，`all` 必须有全校依据；成都/宜宾/峨眉中文名规范化。
- `section_id`、`parent_chunk_id`、`heading_path`、`clause_number`：有原文支持的章节与条款结构。
- `conditions`、`exceptions`、`applicability_evidence`：条件、例外及适用性原文。
- `table_headers`、`footnotes`：有原文支持的表头和脚注。

采纳标注可提供 `structure` 对象，其中包含上述章节、表头和脚注字段。
`section_id` 需有 `heading_path`；结构文字必须存在于对应的已校验原文。
`parent_chunk_id` 使用完整稳定条款 ID，父条款必须在本次同文档采纳集合内，且校区和人群一致，
不能自指或成环。全体适用的父条款可以包含特定人群或校区的例外，互不相容的范围不能关联。
稳定更新后保留旧子条款时，其旧父修订关系只作为溯源，不扩展到新修订。

## 在线适用性与上下文

直接问答与 `search_knowledge` 共用 `query_filters()` 和 `eligible()`。
默认成都校区，用户明确的校区、身份和学年优先于工具参数或上下文默认值；明确其他校区、人群、
学年不匹配、未来生效、禁用、过期、废止及替代资料退出默认查询。旧发布日期不等同失效。
未知校区可作为有明确限制的资料返回，不能标为成都或全校。未知身份下返回已知受限资料时，
分别显示“仅适用于本科生/研究生”等条件。源文档范围未知是资料缺口，不向用户索取来源中缺失的事实。

本轮在线不自动开启历史查询；底层 `RetrievalFilters.historical=True` 兼容接口只为离线检查与既有调用保留。
它不是新增面向用户的历史查询能力，停用的条款仍不可用。

`section_context()` 不改变检索排序或 Recall 分母，工具分别返回 `hits` 和 `context`。
扩展最多 8 个片段、12,000 字符；不截断原文。只允许同来源、文档、修订、章节及相容的校区、人群、
学年；全体规则可扩展当前用户适用的特定例外。相同章节还需相同标题路径。
父条款和明确例外优先，所有补充条款再次经过校区、人群、学年和时间过滤，并分别标明限制。
没有修订/章节绑定的旧条款不自动扩展。

Agent 将补充条款传入模型，并保留各自引用身份；anchor 被 grounding 或 Jev 隐藏时，相关上下文也隐藏。
最终回答的所引资料适用限制由程序保留，模型漏写不能把受限资料显示为通用结论。
来源引用的 `evidence_refs` 与 excerpts 包含 `document_id`、`revision_id`、`locator`、`text_sha256`，
便于定位同一 URL 下的具体修订与原文位置。来源级引用包含各条款引用集合。

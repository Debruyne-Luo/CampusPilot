# 回答中的官方办事链接（2026-10-14）

本轮在已整合的前端中增加“网上办理”卡片。程序从本轮实际引用的已采用资料解析目的地址，
区分“打开办理入口”“打开办事平台”“查看办事指南”；原来的“引用来源 / 查看原文”保留。
没有新建前端设计，没有自动登录、提交表单或完成学校业务。

## 数据及接口

当前本地资料版本仍为 `kb-229ee34eba99ef34`（176 来源、322 片段）。
本轮没有重新发布知识包、修改原文和向量，也没有提交、推送、合并或部署。
工作树包含资料采集任务已有的未提交修改；本轮保留它们，只在相关检索文件中追加链接接线。
线上状态仍以 [LIVE_BASELINE](LIVE_BASELINE.zh-CN.md) 为准。

`SnapshotStore` 在构建每个版本的检索器时，从该不可变版本的原始捕获读取入口。
捕获 manifest、当前文档 revision、正文及 DOM 都校验哈希；只采用有批准条款的文档，
旧捕获的入口不能混入当前版本。旧知识包没有该类捕获时仍可正常回答。
条款原文中明示的官方平台 URL 可以直接解析，模型不得创建目的 URL。

`search_knowledge` 的 hit 增加可选 `service_links`；Agent 的普通与流式最终答案增加同名数组。
只有 `success` / `limited`，且本轮引用的来源或条款与入口相符时才展示。
空结果、待澄清、未通过 grounding 的片段、历史 / 过时 / 待审资料和未采用的网页线索不贡献入口。
生成失败且没有实际引用时不从所有检索结果拼凑链接。

每个元素包含 `id`、`title`、`url`、`kind`（`online` / `platform` / `guide`）、
`source_id`、`source_title`、`source_url`、`requires_login`、`network_requirement`、
`checked_at` 和 `availability`。`checked_at` 是来源核对日期，**不是实时可达性检测日期**；
当前 `availability=not_checked`，界面明确说明当前可用性未核实。
只有原文明示时才标注需登录或校外需校园网 / VPN，其余条件保持未知。

前后端均限制为学校 HTTPS 地址，拒绝账号 / 会话 / 凭据参数、外站或 HTTP 身份认证回跳、
未展开模板、空认证目标、脚本链接等。公开事项标识 `queryCode` 保留。
用户点击后的账号登录、网络条件和实际受理结果由学校系统决定。

## 真实入口检查与限制

独立只读检查共五次公开 GET，没有跟随跳转、读取 Cookie 或登录：

- 生源地贷款捕获入口含 `*default`，本轮请求返回 404。该模板地址不生成按钮，保留原指南。
- 心理预约的 CAS 登录页返回 200，但捕获的 `service` 回跳为 HTTP；按当前 HTTPS 边界
  不生成该申请按钮，保留原指南。登录页可达不表示业务可办。
- 教材结算的一项 `queryCode` 入口返回 412。不能据此判为死链；仍作为原文记录的入口，
  标注可用性未知，尚需浏览器真实验证。
- 财务处和学工平台也返回 412。未将其标为失效或当前办理成功；财务处主页不会被当作直达申请。

两种链接尚未取得可用直接入口时，用户仍可打开官方指南查看路径。
材料中的老版步骤、未知日期及不同身份限制继续由 RAG 适用性和答案校验处理；
新增按钮不等于把这些资料升级为现行制度。
